# ppac-petroleum-api

Free, keyless India petroleum API built from PPAC data (fuel price history for the four metros first, monthly petroleum statistics second).

Status: Phase 1, proving that the daily PPAC PDF can be downloaded from GitHub Actions. No API yet.

Source: Petroleum Planning & Analysis Cell (PPAC), Ministry of Petroleum and Natural Gas, Government of India. Material is reproduced under PPAC's terms (free reproduction, accurate, source acknowledged): https://ppac.gov.in/terms-conditions
